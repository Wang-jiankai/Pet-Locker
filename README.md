## 📌 项目简介

随着携带宠物外出的场景增多，许多场所不允许宠物进入。本项目设计了一款**宠物寄存柜**，由单片机控制整个系统：

- **触控屏**显示柜位状态、信息输入界面
- **密码开锁**或**指纹识别**自动解锁
- **温度 + 声音传感器**检测宠物体温异常或持续嚎叫，自动短信通知主人
- 检测到逃跑、生病等异常情况，及时联系宠物主人

## 🔧 硬件

基于**正点原子 STM32F1 精英开发板** + **2.8 寸 TFTLCD** + **SIM900A** 等模块。

硬件资料：`Hardware/` 目录包含各模块原理图、尺寸图及整体连接图。

## 🔄 版本更新日志
